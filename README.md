# Практическая работа № 4. Процессная аналитика (Process mining)

## Задание

По журналу событий построить графы процесса, выявить узкие места, циклы,
отклонения и оптимальные пути, найти экземпляры процесса с аномально большой
длительностью и сформулировать предложения по оптимизации процесса.

## Данные

**Sepsis Cases – Event Log** (4TU.ResearchData, 2016),
DOI [10.4121/uuid:915d2bfb-7e84-49ad-a286-dc35f063a460](https://doi.org/10.4121/uuid:915d2bfb-7e84-49ad-a286-dc35f063a460).
Путь пациентов с подозрением на сепсис через больницу: 1 050 случаев,
15 214 событий, 16 действий. Файл: `data/Sepsis Cases - Event Log.xes.gz`.

## Структура репозитория

```
analysis.py          анализ журнала (pm4py, pandas, matplotlib) -> outputs/
create_report.py     сборка отчёта .docx из outputs/ (python-docx)
data/                исходный журнал событий XES
outputs/             результаты анализа (перезаписываются при запуске)
report/              шаблон титульного листа и готовый отчёт
tests/               автоматические тесты (unittest)
requirements.txt     зависимости Python
```

## Запуск (Windows)

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python analysis.py
.venv\Scripts\python create_report.py
.venv\Scripts\python -m unittest discover -s tests -v
```

Требуется Python 3.11+. Для PNG-рисунков графов (DFG, сеть Петри, BPMN)
установите Graphviz (https://graphviz.org/download/) и добавьте каталог
`bin` в `PATH`; без него `analysis.py` сохраняет только исходные описания
графов `*.gv`. Тесты запускают `analysis.py` (дважды — для проверки
воспроизводимости) и перезаписывают `outputs/`.

## Основные результаты

* Журнал: 1 050 случаев, 15 214 событий, период 2013-11-07 – 2015-06-05;
  удалено 7 дубликатов. Полных экземпляров (начало с ER Registration и есть
  выписка) — 739, незавершённых — 311. Вариантов — 845, из них 782 единичных.
* Модель (Inductive Miner, шум 0,2): fitness 0,9799, precision 0,3709,
  F1 0,5381; не соответствуют модели 124 эпизода.
* Узкие места: Admission NC → Release A (медиана 67,7 ч); антибиотики
  после ER Sepsis Triage — медиана 1,6 ч, в течение 1 ч — лишь 40,7 %
  случаев, позднее 3 ч — 21,3 %.
* Циклы: 1 029 самопереходов, 40 двухвершинных циклов (главный —
  CRP ⇄ Leucocytes); повторы действий в 743 случаях (70,8 %).
  Повторное обращение (Return ER) — 278 случаев (37,6 %), медиана 47,4 сут
  после выписки.
* Типовой маршрут: ER Registration → ER Triage → ER Sepsis Triage →
  IV Liquid → IV Antibiotics → Admission NC → Release A — 356 случаев
  (48,2 %), медиана 5,21 сут; самый быстрый маршрут (≥ 10 случаев) —
  4,29 сут.
* Длительные экземпляры (> 16,79 сут, Q3 + 1,5·IQR): 55 эпизодов (7,4 %),
  на них приходится 25,7 % суммарного времени госпитализации.
